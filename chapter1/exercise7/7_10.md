if (read(read(cin, data1), data2)) {
    /../
}


内层调用 read(cin, data1)：

从 cin 读取数据存入 data1。

返回 cin 本身（类型为 istream&）。

外层调用 read(..., data2)：

将内层返回的 cin 作为第一个参数，data2 作为第二个参数。

也就是执行 read(cin, data2)。

从 cin 继续读取数据存入 data2。

再次返回 cin。

if 条件判断：

最终，if 括号里的表达式实际上变成了 if (cin)。

在 C++ 中，istream 对象可以隐式转换为 bool 值。当流的状态是有效的（读取成功）时，转换为 true；当流遇到错误（如 EOF、类型不匹配等）时，转换为 false。

这种写法的优点（惯用法）：

代码简洁：把“读取操作”和“状态检查”合并在一行代码中。

链式调用：巧妙地利用了返回流引用的特性，一次性读取多个对象。

安全性：如果第一个 data1 读取就失败了，短路求值（或者流状态的传递）会导致后面的操作无效，直接判定为 false。

这也是 C++ 中处理输入时非常经典的模式，类似于 while (cin >> a >> b) 的原理。
