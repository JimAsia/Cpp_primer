# 练习 7.34

C++ 在编译类定义时，会先扫描并处理完所有成员的声明，但**成员类型别名的声明位置有严格要求**。将其置于最后一行会使得之前所有依赖它的成员声明失败，从而导致编译不通过。

```cpp
class Screen {
public:
    // 其他成员函数声明，使用了 pos
    Screen& move(pos r, pos c); // 编译错误：pos 未知

private:
    // 数据成员，使用了 pos
    pos cursor = 0;              // 编译错误：pos 未知
    pos height = 0, width = 0;   // 编译错误：pos 未知

    // 如果放在这里...
    typedef std::string::size_type pos;
};
```
