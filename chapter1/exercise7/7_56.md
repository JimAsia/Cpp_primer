# 练习 7.56

## 一、什么是类的静态成员？

类的静态成员是指被 `static` 关键字修饰的类数据成员或成员函数。**它们属于类本身，而不属于类的任何一个具体对象。** 无论你创建了多少个该类的对象，静态成员在内存中**只有一份**，所有对象共享这一份数据。

## 二、静态成员的优点

1. **节省内存**：无论创建多少个对象，静态数据成员只占用一份内存，避免了每个对象都拷贝一份相同数据的浪费。
2. **独立于对象**：即使没有创建类的任何对象，也可以通过 `类名::成员名` 直接访问静态成员，常用于工具类、工厂模式或全局状态管理。
3. **更好的封装性**：相比全局变量，静态成员受类的访问控制（`public`、`private`、`protected`）约束，可以将其设为 `private` 防止外部随意修改，同时提供静态成员函数作为访问接口。
4. **类型安全与避免命名冲突**：静态成员属于特定的类作用域，不会像全局变量那样容易引起命名污染。
5. **状态共享**：可以用来跟踪类创建的实例数量，或者维护所有对象共享的配置。

## 三、静态成员与普通成员的区别（核心对比）

| 对比维度 | 静态成员 (Static) | 普通成员 (Non-Static) |
| --- | --- | --- |
| **归属** | 属于类 | 属于具体对象 |
| **内存分配** | 存储在静态存储区（全局区），程序启动时分配，结束时销毁，全局仅一份 | 存储在堆或栈上，随对象的创建而分配，随对象销毁而释放 |
| **访问方式** | 可通过 `类名::成员` 访问，也可通过 `对象.成员` 访问 | 只能通过 `对象.成员` 或 `指针->成员` 访问 |
| **`this` 指针** | 静态成员函数**没有** `this` 指针 | 普通成员函数有隐含的 `this` 指针 |
| **初始化** | 必须在类外部进行定义和初始化（除非是 `constexpr` 或 C++17 后的 `inline` 变量） | 通常在构造函数中初始化（或使用类内初始值） |
| **访问限制** | 静态成员函数**只能直接访问**静态成员，不能直接访问非静态成员 | 普通成员函数可以直接访问静态成员和非静态成员 |

## 示例

```cpp
class Counter {
public:
    Counter() { ++count; } // 每次创建对象，count 加 1
    ~Counter() { --count; }

    // 静态成员函数：没有 this 指针
    static int getCount() {
        // return val; // 错误：不能直接访问非静态成员 val
        return count;  // 正确：只能访问静态成员
    }

private:
    int val;          // 普通成员
    static int count; // 静态数据成员声明
};

// 静态成员必须在类外定义并初始化
int Counter::count = 0;

int main() {
    Counter c1, c2;
    // 通过类名直接访问静态成员函数，无需对象
    std::cout << Counter::getCount() << std::endl; // 输出 2
    return 0;
}
```
