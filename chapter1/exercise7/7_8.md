1.为什么 read 函数使用普通引用（Sales_data&）？

必须修改实参： read 函数的作用是从输入流中读取数据，并写入到传入的 Sales_data 对象中。它需要修改对象内部的成员变量（如 isbn、units_sold、revenue 等）。如果使用常量引用，就无法修改对象；如果使用值传递（传值），修改的只是副本，原对象不会改变。所以必须使用普通引用。

避免拷贝： 使用引用可以避免将实参拷贝给形参。如果使用传值方式，会调用拷贝构造函数，增加不必要的性能开销。

2.为什么 print 函数使用常量引用（const Sales_data&）？

只读不写： print 函数的作用仅仅是将对象的内容输出到流中，它不需要也不应该修改对象的状态。将其参数声明为 const 引用，可以防止在函数内部意外修改对象，提高了代码的安全性和健壮性。

避免拷贝： 同样地，使用引用传递（而不是值传递）是为了避免拷贝大对象带来的性能损耗。

兼容性更广： 常量引用可以接受常量对象（const Sales_data）作为参数，也可以接受非常量对象作为参数；而普通引用只能接受非常量对象。由于 print 是只读操作，将它设计成接受常量引用，意味着它既能打印普通对象，也能打印常量对象，适用范围更广。

总结：
read 需要写数据，所以不能用 const；print 只读数据，为了安全加上了 const。两者都用引用，是为了避免不必要的拷贝，提高程序运行效率。
