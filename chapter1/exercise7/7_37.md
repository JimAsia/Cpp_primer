# 练习 7.37

## `Sales_data first_item(cin);`

- **使用的构造函数**：`Sales_data(std::istream &is)`（流构造函数）。
- **数据成员的值**：

| 成员 | 值 |
| --- | --- |
| `bookNo` | 由运行时用户通过标准输入 `cin` 输入的值决定 |
| `units_sold` | 由用户输入决定 |
| `revenue` | 由用户输入决定 |

## `Sales_data next;`（在 `main` 函数内）

- **使用的构造函数**：`Sales_data(std::string s = "")`。因为没有提供实参，这里的 `s` 使用了默认实参 `""`，因此它充当了**默认构造函数**。
- **数据成员的值**：

| 成员 | 值 |
| --- | --- |
| `bookNo` | 初始化为 `""`（空字符串） |
| `units_sold` | 初始化为 `0`（依靠类内初始值） |
| `revenue` | 初始化为 `0.0`（依靠类内初始值） |

## `Sales_data last("9-999-99999-9");`

- **使用的构造函数**：`Sales_data(std::string s = "")`。传入了一个字符串字面量，隐式转换为 `std::string` 绑定到参数 `s` 上。
- **数据成员的值**：

| 成员 | 值 |
| --- | --- |
| `bookNo` | 初始化为 `"9-999-99999-9"` |
| `units_sold` | 初始化为 `0` |
| `revenue` | 初始化为 `0.0` |
