# 练习 7.35

```cpp
typedef string Type;
Type initVal();
class Exercise {
public:
    typedef double Type;
    Type setVal(Type);
    Type initVal();
private:
    int val;
};

// 修改点：将返回类型改为 Exercise::Type
Exercise::Type Exercise::setVal(Type parm) {
    val = parm + initVal(); // 这里的 initVal() 调用的是类内的，返回 double
    return val;             // val 是 int，会隐式转换为 double 返回，可能有警告但语法正确
}
```
