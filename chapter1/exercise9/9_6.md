❌ 错误原因
std::list 的底层是双向链表，它的迭代器属于双向迭代器（Bidirectional Iterator）。双向迭代器只支持：

相等/不等比较：==、!=

自增/自减：++、--

它不支持 <、>、<=、>= 这些关系运算符（只有 vector、deque 等随机访问迭代器才支持）。因此 iter1 < iter2 会导致编译错误。

✅ 修改方法
将 while (iter1 < iter2) 改为 while (iter1 != iter2)。

修改后的代码：
cpp
list<int> lst1;
list<int>::iterator iter1 = lst1.begin(), iter2 = lst1.end();
while (iter1 != iter2) /* ... */
💡 补充说明
在 C++ 标准库中，遍历容器时推荐统一使用 != 来比较迭代器，而不是 <。这样做的好处是：

通用性强：适用于所有类型的容器（vector、list、map、set 等），无论其迭代器是哪种类型。

避免越界：防止因迭代器越界导致 < 比较产生未定义行为。

只有当你确实需要随机访问（比如 iter + n 或比较前后顺序）时，才应该使用 <，并且此时容器类型必须是 vector 或 deque。
