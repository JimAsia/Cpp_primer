# 练习 9.17

**题目**：假设 `c1` 和 `c2` 是容器，`if (c1 < c2)` 这个用法对 `c1` 和 `c2` 的类型有什么（如果有）限制？

## 限制一：`c1` 和 `c2` 必须是相同类型的容器

你不能把一个 `vector` 和一个 `list` 进行比较，也不能把一个 `vector<int>` 和一个 `vector<double>` 进行比较。它们必须是完全相同的容器类型（例如，两个都是 `vector<int>`）。

## 限制二：容器内的元素类型必须支持 `<` 运算符

容器之间的比较，本质上是逐个比较里面的元素（字典序比较）。因此，容器里存的元素必须能使用小于号 `<` 进行比较。

- 如果是**内置类型**（如 `int`、`double`、`char`），天然支持，没问题。
- 如果是**自定义的类**（比如你自己写了一个 `Person` 类），除非你为这个类重载了 `<` 运算符，否则编译器不知道该怎么比，就会报错。

## 限制三：不能是 `unordered_*` 无序容器

C++ 标准库中的无序容器（如 `unordered_map`、`unordered_set`）不支持 `<` 和 `>` 运算符。因为它们内部的元素是无序的，比较大小没有意义。它们只支持 `==` 和 `!=`。

> _注：`array` 容器也是支持的，`string` 虽然算是容器，但也支持。_

## 💡 扩展理解：它是怎么比较的？（字典序比较）

标准库容器（如 `vector`、`list`、`deque` 等）的 `<` 比较采用的规则叫做**"字典序比较"（Lexicographical comparison）**，和查字典极其相似：

1. **逐个对比**：从第一个元素开始，依次比较两个容器对应位置的元素。

2. **一锤定音**：如果对应位置的元素不相等，那么这两个元素的比较结果，就是整个容器的比较结果。
   - 例如：`{1, 2, 5}` 和 `{1, 2, 3}`，前两个元素相同，第三个元素 5 > 3，所以整个容器 `c1 > c2`。

3. **长度决胜**：如果两个容器前面的所有元素都对应相等，但长度不一样，那么元素较少的容器较小（短的小于长的）。
   - 例如：`{1, 2}` 和 `{1, 2, 3}`，前面都一样，但前者短，所以 `c1 < c2`。

## 💻 代码示例

```cpp
#include <vector>
#include <list>
#include <string>
#include <unordered_set>

using namespace std;

int main() {
    vector<int> v1 = {1, 2, 3};
    vector<int> v2 = {1, 2, 4};
    if (v1 < v2) { /* ✅ 合法：同类容器，元素支持 < 比较 */ }

    // vector<int> v3 = {1, 2};
    // list<int> l1 = {1, 2};
    // if (v3 < l1) { /* ❌ 编译错误：容器类型不同 */ }

    // vector<string> vs1 = {"a"};
    // vector<string> vs2 = {"b"};
    // if (vs1 < vs2) { /* ✅ 合法：string 内部重载了 < 运算符 */ }

    // unordered_set<int> s1 = {1};
    // unordered_set<int> s2 = {2};
    // if (s1 < s2) { /* ❌ 编译错误：无序容器不支持 < 比较 */ }
}
```
