应该使用 reserve() 成员函数预先分配至少容纳 100 个字符的内存空间。

std::string s;
s.reserve(100); // 预先分配至少 100 个字符的 capacity
char c;
while (std::cin >> c) { // 或者使用 std::cin.get(c)
    s.push_back(c);     // 或 s += c;
}

避免频繁的内存重新分配（Reallocation）：
如果没有使用 reserve，string 默认的 capacity 通常很小（或者为 0）。当不断往 string 中逐个添加字符，且元素数量超过当前 capacity 时，string 必须：

申请一块更大的连续内存。

将旧内存中的所有字符拷贝到新内存中。

释放旧内存。
这个过程会随着字符的不断添加而反复发生，是非常耗时的操作。

一次性分配到位：
既然题目已知“最少需要读取 100 个字符”，通过调用 s.reserve(100)，string 会一次性分配足够容纳 100 个字符的底层数组。这意味着在读取前 100 个字符的过程中，push_back 只是简单地在已有内存的末尾写入字符并更新 size，彻底避免了扩容和数据拷贝的开销。

注意（扩展说明）：
题目说的是“最少需要读取 100 个字符”。如果实际读取的字符数远超 100 个（例如读了 1000 个），那么在超过 100 个之后，string 依然会进行自动扩容（通常按 2 倍或 1.5 倍增长）。但即便如此，预先 reserve(100) 依然免去了最初阶段最频繁的几次微小扩容，性能收益极大。
