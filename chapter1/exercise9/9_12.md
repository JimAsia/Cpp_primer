# 练习 9.12

## 1. 接受一个容器（拷贝构造函数）

- **形式**：`C c(other_c);`
- **参数**：一个已经存在的、相同类型的容器对象。
- **限制**：要求两个容器的类型完全一致，并且容器中存储的元素类型也完全一致。例如，不能用 `list<int>` 去构造 `vector<int>`。
- **拷贝范围**：拷贝原容器中的**所有**元素。

## 2. 接受两个迭代器（范围构造函数）

- **形式**：`C c(b, e);`（`b` 是起始迭代器，`e` 是尾后迭代器）
- **参数**：两个迭代器，表示一个范围 `[b, e)`（左闭右开区间）。
- **限制**：容器类型可以不同（比如可以用 `list` 构造 `vector`），只要两个迭代器指向的元素类型可以转换为新容器所需的元素类型即可。
- **拷贝范围**：只拷贝迭代器指定的部分元素（即 `[b, e)` 范围内的元素）。

## 对比

| 对比项 | 接受一个容器 | 接受两个迭代器 |
| --- | --- | --- |
| **形式** | `C c(other_c);` | `C c(b, e);` |
| **容器类型** | 必须完全一致 | 可以不同 |
| **元素类型** | 必须完全一致 | 可转换即可 |
| **拷贝范围** | 全部元素 | `[b, e)` 区间 |

## 💻 代码示例直观对比

```cpp
#include <iostream>
#include <vector>
#include <list>
#include <string>

using namespace std;

int main() {
    list<string> my_list = {"apple", "banana", "cherry", "date"};

    // 1. 使用【接受一个容器】的构造函数（要求类型完全一致）
    list<string> copy_list(my_list); // ✅ 合法：list<string> 拷贝 list<string>
    // vector<string> error_vec(my_list); // ❌ 编译错误：不能用 list 直接构造 vector

    // 2. 使用【接受两个迭代器】的构造函数（允许类型不同，可以截取部分）
    // 将 my_list 的元素拷贝给 vector，这里展示了不同容器之间的转换
    vector<string> sub_vec(my_list.begin(), my_list.end()); // ✅ 合法：list 迭代器 -> vector

    // 上面这行其实拷贝了所有元素，下面这个只拷贝一部分：
    vector<string> part_vec(++my_list.begin(), my_list.end()); // 只拷贝 {"banana", "cherry", "date"}
}
```
