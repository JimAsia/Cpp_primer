p2 - p1 得到的是一个整数偏移量，表示从 p1 到 p2 相隔多少个元素。

将这个偏移量加到 p1 上（p1 + (p2 - p1)），实际上就是将 p1 向前（或向后）移动相应的步数。

由于 (p2 - p1) 正好是 p2 相对于 p1 的位置差，所以 p1 加上这个差值后，新的 p1 就会指向原来 p2 所在的位置。

结论： 该程序的功能是将指针 p1 移动到指针 p2 原来所指向的同一个元素位置（即让 p1 和 p2 指向同一个元素）。

2. 什么情况下该程序是非法的？

（1）指针类型不匹配（语法非法）
指针的减法运算 p2 - p1 要求 p1 和 p2 必须是指向相同类型的指针（或者至少是兼容的类型，如 void* 在 C 中不能直接相减）。
如果 p1 和 p2 的类型不同（例如 p1 是 int*，p2 是 char*），编译器通常会报错或发出警告，因为无法确定它们之间的步长基准。
在这种情况下，该语句在编译时就是非法的。

（2）不在同一个数组中（行为未定义/逻辑非法）
题目假定它们指向同一个数组，但如果这个前提不成立，即 p1 和 p2 不是指向同一个数组（或同一个对象的末尾）的元素时：
根据 C 标准，两个指针相减的前提是它们必须指向同一个数组对象。如果它们指向不同的内存区域，p2 - p1 的结果是未定义的（Undefined Behavior）。
此时，ptrdiff_t 类型可能无法正确表示两个不同对象之间的“距离”，计算结果可能溢出或毫无意义。
进而 p1 += ... 的结果也是未定义的，p1 可能会变成一个无效的指针，甚至导致程序崩溃。

（3）总结非法情况
严格意义上的“非法”（编译不通过）： 当 p1 和 p2 是指向不同数据类型的指针时（且不能隐式转换为同一类型），不能进行减法运算，该语句非法。
运行时的非法（未定义行为）： 如果 p1 和 p2 虽然类型相同，但没有指向同一个数组，那么该语句的执行结果是未定义的，这在逻辑上属于非法使用。
