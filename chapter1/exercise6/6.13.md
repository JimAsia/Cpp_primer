# 练习 6.13

按值传递与按引用传递的对比：

| 特性 | `void f(T)`（按值） | `void f(T&)`（按引用） |
| :--- | :--- | :--- |
| **参数本质** | 实参的副本 | 实参的别名 |
| **对实参的影响** | 函数内修改不影响实参 | 函数内修改会改变实参 |
| **性能开销** | 需要拷贝实参（大对象开销大） | 无拷贝，效率高 |
| **空值情况** | 值参数可以是默认值（如 0） | 引用必须绑定到有效对象，不能为 `nullptr` |
| **使用场景** | 函数不需要修改实参，且对象较小 | 函数需要修改实参，或对象较大需避免拷贝 |
