## 6.40 默认参数的位置规则

**(b) 是错误的。**

原因分析：在 C++ 中，带有默认参数的函数必须遵循**"从右向左连续定义"**的规则 —— 也就是说，如果一个参数设定了默认值，那么它右边的所有参数都必须有默认值。

| 声明 | 是否合法 | 说明 |
| --- | :---: | --- |
| (a) `int ff(int a, int b = 0, int c = 0);` | ✅ | `b` 和 `c` 都有默认值且位于参数列表右侧，符合规则 |
| (b) `char *init(int ht = 24, int wd, char bckgrnd);` | ❌ | `ht` 有默认值，但它右边的 `wd` 和 `bckgrnd` 却没有默认值，违反规则 |

## 6.41 默认参数的使用

```cpp
char *init(int ht, int wd = 80, char bckgrnd = ' ');
```

### `init();` 是非法的

原因：函数 `init` 的第一个参数 `ht` 没有默认值。调用 `init()` 时没有提供任何参数，导致缺少必要的实参 `ht`，编译器会报错（参数数量不匹配）。

### 哪个调用虽然合法但显然与程序员的初衷不符？为什么？

**答案：(b) `init(24, 10);` 和 (c) `init(14, '*');`**

- **(b) `init(24, 10);`**：这里 `24` 传给了 `ht`，`10` 传给了 `wd`，`bckgrnd` 使用默认值 `' '`。语法完全合法。但从程序员的角度看，若本意是把背景字符 `bckgrnd` 设置为某个值（比如 ASCII 码为 10 的换行符），那么这个传参位置就是错的 —— 宽度被意外改成 10，而背景没有变化。

- **(c) `init(14, '*');`**：这里 `14` 传给了 `ht`，字符 `'*'` 被隐式转换为整型（ASCII 码 42）传给了 `wd`，`bckgrnd` 仍然使用默认值 `' '`。语法合法，能编译通过。但程序员的本意显然是想把背景字符 `bckgrnd` 设置为 `'*'`，却错误地把它写在了第二个参数的位置。结果是背景依然是空格，而宽度 `wd` 变成了 42，显然与初衷严重不符。

**正确写法**：若要实现初衷，应写成 `init(14, 80, '*');`；如果只想改背景，也可用 `init(0, 80, '*');`（假设第一个参数必需）。
