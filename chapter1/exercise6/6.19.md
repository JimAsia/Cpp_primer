double calc(double);
int count(const string &, char);
int sum(vector<int>::iterator, vector<int>::iterator, int);
vector<int> vec(10);
(a) calc(23.4, 55.1);      (b) count("abcda", 'a');
(c) calc(66);               (d) sum(vec.begin(), vec.end(), 3.8);

(a) 不合法：calc 只接受 1 个参数，但调用了 2 个参数，参数个数不匹配。
(b) 合法：字符串字面量可隐式构造 string 对象绑定到 const string &。
(c) 合法：int 可隐式转换为 double。
(d) 合法：double 可隐式转换为 int（截断小数部分）。
