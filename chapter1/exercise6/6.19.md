# 练习 6.19

**题目**：判断下列调用是否合法，并说明原因。

```cpp
double calc(double);
int count(const string &, char);
int sum(vector<int>::iterator, vector<int>::iterator, int);
vector<int> vec(10);

(a) calc(23.4, 55.1);      (b) count("abcda", 'a');
(c) calc(66);              (d) sum(vec.begin(), vec.end(), 3.8);
```

## 逐项分析

| 调用 | 是否合法 | 原因 |
| --- | :---: | --- |
| **(a)** `calc(23.4, 55.1)` | ❌ 不合法 | `calc` 只接受 1 个参数，这里却传了 2 个，参数个数不匹配 |
| **(b)** `count("abcda", 'a')` | ✅ 合法 | 字符串字面量可隐式构造 `string` 对象，绑定到 `const string &` |
| **(c)** `calc(66)` | ✅ 合法 | `int` 可隐式转换为 `double` |
| **(d)** `sum(vec.begin(), vec.end(), 3.8)` | ✅ 合法 | `double` 可隐式转换为 `int`（截断小数部分） |
