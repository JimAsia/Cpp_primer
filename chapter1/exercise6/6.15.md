# 练习 6.15

## 参考代码

```cpp
// 返回 s 中 c 第一次出现的位置索引
// 引用形参 occurs 负责统计 c 出现的总次数
string::size_type find_char(const string &s, char c,
                            string::size_type &occurs)
{
    auto ret = s.size();        // 第一次出现的位置（如果有的话）
    occurs = 0;                 // 设置表示出现次数的形参的值
    for (decltype(ret) i = 0; i != s.size(); ++i) {
        if (s[i] == c) {
            if (ret == s.size())
                ret = i;        // 记录 c 第一次出现的位置
            ++occurs;           // 将出现的次数加 1
        }
    }
    return ret;                 // 出现次数通过 occurs 隐式地返回
}
```

## 为什么 `s` 是 `const string &`（常量引用）？

| 要点 | 说明 |
| --- | --- |
| **作用** | 输入参数。函数只需要"读取"字符串 `s` 的内容，完全不需要修改它 |
| **为什么用引用 `&`** | `string` 对象内部可能包含大量字符。若按值传递，每次调用都要把整个字符串完整复制一份，性能上非常浪费；使用引用只传递一个指向原字符串的地址，无论字符串多长都几乎不消耗额外空间 |
| **为什么用 `const`** | 为了安全。加上 `const` 限制后，若在函数内部不小心写了 `s[0] = 'A';` 这样的修改操作，编译器会直接报错，从而防止意外修改原始数据 |

## 为什么 `occurs` 是 `string::size_type &`（普通引用）？

| 要点 | 说明 |
| --- | --- |
| **作用** | 输出参数。函数需要把"字符出现的总次数"返回给调用者 |
| **为什么用引用 `&`** | 因为函数已经用 `return ret` 返回了"第一次出现的位置"，一个函数不能返回两个值，所以必须找一个"旁路"把次数传出去。普通引用允许函数内部直接修改外部传入的变量，从而实现数据传出 |
| **为什么不能用 `const`** | 如果写成 `const ... &occurs`，函数内部就绝对不允许修改它（`++occurs` 会报错），那么这个参数就失去了"返回统计次数"的意义 |

## 为什么 `c` 是 `char`（按值传递）？

- **作用**：输入参数，用于查找的目标字符。
- **为什么不加引用**：`char` 是基本数据类型，通常只占 1 个字节。复制一个字符的开销极小，完全不需要为了节省空间而使用引用。而且字符不需要传出数据，按值传递最直观、最安全。
