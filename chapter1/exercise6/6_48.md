找到了目标单词（s == sought）：
此时 s != sought 为 false，循环条件 cin >> s && s != sought 中，&& 的右侧为假，循环终止。
注意：由于 && 的短路特性，当 cin >> s 为 true 且 s != sought 为 false 时，cin 的状态是正常的（因为刚刚成功读取了 sought）。
此时 assert(cin) 为 true，断言通过。
未找到目标单词，输入流结束（EOF）或出错：
此时 cin >> s 返回 false（因为读到末尾或出错），循环条件为假，循环终止。
此时 cin 的状态是 fail 或 eof（即布尔值为 false）。
此时 assert(cin) 为 false，断言失败，程序会终止。


string s;
while (cin >> s && s != sought) { } // 空函数体
assert(cin);
