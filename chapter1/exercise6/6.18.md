# 练习 6.18

**题目**：为下列函数编写声明。

```cpp
bool compare(matrix &a, matrix &b);
vector<int>::iterator change_val(int i, vector<int>::iterator j);
```

## 声明解析

| 函数 | 参数 | 返回类型 | 说明 |
| --- | --- | --- | --- |
| `compare` | 两个 `matrix` 对象的引用 | `bool` | 比较两个矩阵 |
| `change_val` | 一个 `int`、一个 `vector<int>::iterator` | `vector<int>::iterator` | 修改迭代器所指元素的值 |
