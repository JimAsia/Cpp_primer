2. double* dp = &i;
非法
原因：指针的类型必须与它指向的对象类型严格匹配。dp 是一个指向 double 类型的指针，而 &i 获取的是一个 int 类型变量的地址。在 C++ 中，不能直接将 int* 类型的地址赋值给 double* 类型的指针（除非使用强制类型转换，但这里没有）。

3. int *ip = i;
非法
原因：指针变量存放的必须是内存地址，而不是变量的值。这里 i 的值是整数 0，你试图把一个整数值直接赋给指针变量 ip。除了整数常量 0（或 NULL/nullptr）可以表示空指针外，不能把其他整数直接赋给指针。

4. int *p = &i;
合法
原因：p 是一个指向 int 类型的指针，&i 获取的正是 int 类型变量 i 的地址。类型完全匹配，且使用的是取地址符 &，这是最标准的指针初始化方式。
